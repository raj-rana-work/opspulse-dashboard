# OpsPulse: Fleet Intelligence & Predictive Telemetry Hub

**Live Web App:** [Launch OpsPulse on Streamlit](https://your-streamlit-app-link-here.streamlit.app)  
**Built With:** Python, Streamlit, Pandas, Scikit-Learn, NumPy

## Overview

OpsPulse bridges Client Systems Operations, Predictive Machine Learning, and Enterprise IT Strategy. Rather than reacting to device crashes and user tickets after productivity is lost, OpsPulse ingests endpoint telemetry across 1,000 enterprise workstations to calculate composite risk scores and forecast hardware failures before they occur.

## Key Capabilities

* **Role-Tailored Personas:** Instantly toggle between high-level SLA governance and financial risk (CIO View) and tactical endpoint triage queues (Tier-1 Field Tech View).
* **Zero-Day Chaos Simulator:** Interactive threat injection slider dynamically stresses fleet patch drift, simulated ransomware pressure, and projected downtime costs in real time.
* **Predictive ML Diagnostic:** Embedded Scikit-Learn Random Forest classifier assessing 7-day critical failure likelihood based on hardware age, reboot latency, missing security updates, and BSOD error history.
* **Automated Triage Dispatch:** One-click CSV export prioritizing endpoints requiring urgent remediation, re-imaging, or physical component replacement.
